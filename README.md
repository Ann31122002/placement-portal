Placement Training And Preparation Portal
This is a full-stack web application developed using the Django framework to simplify and automate campus placement activities for colleges and universities. The platform helps students, administrators, and recruiters efficiently manage placement-related processes including job postings, applications, assessments, interview scheduling, and result tracking.


Features
 Secure User Authentication (Student & Admin)
 Job Posting and Application Management
 Interview Scheduling and Tracking
 Technical & Aptitude Assessments
 Student Performance and Response Tracking
 Exportable User Data and Reports
 Placement Notifications and Updates
 Responsive and User-Friendly Interface


Technologies Used
 Frontend: HTML, CSS, JavaScript
 Backend: Python, Django
 Database: SQLite
 Tools: Git, GitHub, VS Code

Installation & Setup
  1️⃣ Clone the Repository
  git clone https://github.com/Ann31122002/placement-portal.gitcd placement-portal

  2️⃣ Create Virtual Environment
   python -m venv env

  3️⃣ Activate Virtual Environment
  Windows
  env\Scripts\activate
  
  Mac/Linux
  source env/bin/activate

  4️⃣ Install Dependencies
  pip install -r requirements.txt

  5️⃣ Apply Database Migrations
  python manage.py migrate

  6️⃣ Run the Development Server
  python manage.py runserver

  7️⃣ Open in Browser
  http://127.0.0.1:8000/
