Your quick reference guide for quantitative preparation.

Time, Speed, and Distance (TSD)

1. Basic Speed
Speed = Distance / Time
2. Unit Conversion
x km/hr = x * (5/18) m/s
3. Average Speed
Avg. Speed = Total Distance / Total Time
4. Relative Speed (Opposite Direction)
S_rel = S1 + S2

Time and Work

5. Work Rate (Individual)
A's 1-Day Work = 1 / Days_taken_by_A
6. Combined Work Rate
1/Days_Combined = 1/Days_A + 1/Days_B
7. Men, Days, Work (Chain Rule)
(M1 * D1) / W1 = (M2 * D2) / W2

Averages & Mixtures

8. Average (Mean)
Average = Sum of Observations / Number of Observations
9. Average of N Natural Numbers
Avg = (N + 1) / 2
10. Alligation Rule (Mixtures)
Ratio of Quantities = (C2 - Cm) / (Cm - C1)

C1, C2 = Cost of Quantity 1, 2; Cm = Mean Cost

Percentages, P&L, and Interest

11. Simple Interest (SI)
SI = (P * R * T) / 100
12. Amount (Compound Interest)
A = P (1 + R/100)ᵀ
13. Profit Percentage
P% = (Profit / CP) * 100
14. Selling Price (SP - Profit)
SP = CP * (100 + P%) / 100
15. Percentage Change
Change% = (|New - Old| / Old) * 100

P&C and Probability

16. Permutations (Arrangement)
ⁿPᵣ = n! / (n - r)!
17. Combinations (Selection)
ⁿCᵣ = n! / [r! * (n - r)!]
18. Basic Probability
P(E) = Favorable Outcomes / Total Outcomes

Ratios & Proportion

19. Cross Product Rule
If a:b :: c:d, then a * d = b * c
20. Mean Proportional
Mean Proportional of a and b = √(a * b)
